
# Thompson Sampling

Thompson sampling is known to be the first bandit algorithm (Thompson 1933) in the bandit literature. Here again the algorithm will try to balance between exploration and exploitation but now this is done using the well known Bayesian idea, that is *updating priors*. So as in the Bayesian setting, here first we will assume we have a prior distribution for the potential reward distributions (i.e., these are distributions over distributions) and then update the priors at each time after observing the reward. Let us quickly introduce some notations and then we will outline the Thompson Sampling algorithm. 

Like before we let the potential reward for any fixed arm $k$ follows $Y_t(k) \sim \mathbb{P}^{\mu(k)}$ where  $\mu(k) = \mathbb{E}[Y_t(k)]$. The prior distribution (in short we will call just prior) at time $t$ for arm $k$ will be denoted by $\mathbb{P}^{\widehat{\theta}_{t}(k)}$, where $\widehat{\theta}_{t}(k)$ is the parameter of the prior, i.e., at time $t$ we assume $\mu(k) \sim  \mathbb{P}^{\widehat{\theta}_{t}(k)}$ (here $\mu(k)$ is random). Now at $t = 0$, we start with $\widehat{\theta}_{0}(k) =  \overline{\theta}(k)$, where $\overline{\theta}(k)$ is a fixed number we set externally and then after observing the sample at time time $t$, conditional on the observation (or applying the Bayesian principle) we update the parameter of the prior $\widehat{\theta}_{t}(k)$ (which is now the posterior at time $t$).
#### Thompson Sampling Algorithm (General Parametric Case)
 **Input** : $\mathcal{W}$, $T$, $\overline\theta(k)$ $\forall k \in \mathcal{W}$
 **Initialize** :  $\widehat{\theta}_{0}(k) = \overline\theta(k)$ $\forall k \in \mathcal{W}$ 
 ***for***  $t = 1, \dots, T$
	 1. sample $\mu^{\prime}_{t}(k) \sim \mathbb{P}^{\widehat{\theta}_{t-1}(k)} \text{ for all } k \in \mathcal{W}$
	 2. pick $W_t = \arg\max_{k\in \mathcal{W}} \mu^{\prime}_{t}(k)$
	 3. observe $Y_t$
	 4. update $\widehat{\theta}_t(W_t)$ (update only for the arm $W_t$, others will remain same)

In words, the key steps are following, at each time $t$,
	- for all arms generate a random mean $\mu^{\prime}_{t}(k)$ from the prior distribution $\mathbb{P}^{\widehat{\theta}_{t-1}(k)}$ that we estimated at time $t-1$.
	- pick the arm with the highest sampled mean,
	- observe the reward for the selected arm.
	- update the prior distribution (which is the posterior distribution) for the selected arm, only update $\widehat{\theta}_{t}(W_t)$
## Example -  Bernoulli Rewards (with Beta priors)

Possibly the most well known example of Thompson Sampling is we assume the reward $Y_t(k) \sim \text{Bernoulli}(p(k))$ where $\mu(k) = \mathbb{E}[Y_t(k)]= p(k)$ is the success probability. Assume the prior distribution, 

$$
p(k) \sim \text{Beta}(\widehat{\alpha}_{t}(k),\widehat{\beta}_{t}(k))
$$
where $\widehat{\alpha}_{t}(k)$ and $\widehat{\beta}_{t}(k)$ are parameters of the prior distribution after we have observed sample up-to time period $t$ (including $t$). At  $t = 0$, we can set $\widehat{\alpha}_{0}(k) = \overline{\alpha}(k)$ and $\widehat{\beta}_{0}(k) = \overline{\beta}(k)$. Then using this it is possible to derive the closed form expression of these parameters using Bayesian update formula where 

$$
\begin{align}
    \widehat{\alpha}_{t}(k) = \overline{\alpha}(k) + \sum_{s = 1}^{t} \mathbf{1}\{W_s = k\} Y_s = \overline{\alpha}(k) + S_t(k) \text{ and } \\
    \widehat{\beta}_{t}(k) = \overline{\beta}(k) + \sum_{s = 1}^{t} \mathbf{1}\{W_s = k\} (1 - Y_s) = \overline{\beta}(k) + n_t(k) - S_t(k)
\end{align}
$$

where $S_t(k) = \sum_{s = 1}^{t} \mathbf{1}\{W_s = k\} Y_s$  is the cumulative reward came from playing arm $k$ up-to time $t$ and $n_t(k) = \sum_{s = 1}^{t} \mathbf{1}\{W_s = k\}$ is the cumulative counts of how many times arm $k$ has been played up-to time $t$ (including $t$). With this update formula, we can now outline the Thompson Sampling algorithm for Bernoulli rewards. With this update equations now we can explicitly write down the Thompson Sampling algorithm for Bernoulli rewards. 
#### Thompson Sampling Algorithm (Bernoulli Rewards)
 **Input** : $\mathcal{W}$, $T$, $\overline\alpha(k)$, $\overline\beta(k)$  $\forall k \in \mathcal{W}$
 **Initialize** :  $\widehat{\alpha}_{0}(k) = \overline\alpha(k)$, $\widehat{\beta}_{0}(k) = \overline{\beta}(k)$, $S_0(k) = 0$ and $n_0(k) = 0$  for all $k \in  \mathcal{W}$
 ***for***  $t = 1, \dots, T$
	 1. sample $p^{\prime}_{t}(k) \sim \text{Beta}(\widehat{\alpha}_{t-1}(k),\widehat{\beta}_{t-1}(k)) \text{ for all } k \in \mathcal{W}$
	 2. pick $W_t = \arg\max_{k\in \mathcal{W}} p^{\prime}_t(k)$ , let $W_t = k^{\prime}$
	 3. observe $Y_t$
	 4. update 
$$\begin{align}
  	S_t(k^{\prime}) = S_{t-1}(k^{\prime})+ Y_t \\
 		n_t(k^{\prime}) = n_{t-1}(k^{\prime})+ 1
     \end{align} 
$$
	5. update (using the formulas above) 
$$ 
\begin{align}
\widehat{\alpha}_{t}(k^{\prime}) = \overline{\alpha}(k^{\prime}) + S_{t}(k^{\prime}) \\
\widehat{\beta}_{t}(k^{\prime}) = \overline{\beta}(k^{\prime}) + n_{t}(k^{\prime}) - S_{t}(k^{\prime})
\end{align} 
$$

Note for the Bernoulli Thompson Sampling it is possible to do a recursive update of the posterior parameters directly, in that case there is no need to keep track of $S_t(k)$ and $n_t(k)$ that we did in line 4, and the update will be 

$$
\begin{align}
	\widehat{\alpha}_{t}(W_t) &= \widehat{\alpha}_{t - 1}(W_t) + Y_t, \\
	\widehat{\beta}_{t}(W_t) &= \widehat{\beta}_{t - 1}(W_t) + 1 - Y_t 
\end{align}
$$

## Example - Gaussian Rewards (with known variance and Gaussian Priors)

Now let's look at another well known case of the Thompson sampling which assuming Gaussian rewards with known variance. In particular assume $\forall k \in \mathcal{W}$,  $Y_t(k) \sim \mathcal{N}(\mu(k), \sigma^2(k))$ where $\mu(k) = \mathbb{E}[Y_t(k)]$ are *unknown* to the learner but the variances $\mathbb{V}\text{ar}[Y_t(k)] = \sigma^2(k)$ for all $k$ are  *known*. For the prior in this case we assume Gaussian priors, i.e.,  $\mu(k) \sim \mathcal{N}(\widehat{\mu}_{t}(k), \widehat{\sigma}_{t}^{2}(k))$, where  $\widehat{\mu}_{t}(k)$ and $\widehat{\sigma}_{t}^2(k))$ are the parameters of the prior distribution (Note we only assumed prior for mean!). At $t = 0$, we assume $\widehat{\mu}_{0}(k) = \overline{\mu}(k)$ and $\widehat{\sigma}^2_{0}(k) = \overline{\sigma}^2(k)$, where $\overline{\mu}(k)$ and $\overline{\sigma}^2(k)$ are the initial priors that we set

$$
\begin{align}
    \widehat{\sigma}_{t}^2(k) &= \cfrac{1}{\cfrac{ \sum_{s = 1}^{t}\mathbf{1}\{W_s = k\} }{\sigma^2(k)}+\cfrac{1}{\overline{\sigma}^2(k)}} \quad
= \quad  \cfrac{1}{\cfrac{n_t(k)}{\sigma^2(k)}+\cfrac{1}{\overline{\sigma}^2(k)}} \\ \\
\\ \\
        \widehat{\mu}_{t}(k) &= \left(\frac{\sum_{s = 1}^{t} \mathbf{1}\{W_s = k\} Y_s}{\sigma^2(k)} + \frac{\overline{\mu}(k)}{\overline{\sigma}^2(k)}\right) \;\widehat{\sigma}_{t}^2(k)= \left(\frac{S_t(k)}{\sigma^2(k)} + \frac{\overline{\mu}(k)}{\overline{\sigma}^2(k)}\right) \; \widehat{\sigma}^2_{t}(k) 
\end{align}
$$


The specific algorithm will be exactly same how we wrote the algorithm for the Bernoulli case, except the update formulas are now different.
#### Thompson Sampling Algorithm (Gaussian Rewards)
 **Input** : $\mathcal{W}$, $T$, $\sigma^{2}(k)$, $\overline{\sigma}^{2}(k)$, $\overline{\mu}(k)$   $\forall k \in \mathcal{W}$
 **Initialize** : $\widehat{\sigma}_{0}^{2}(k) = \overline{\sigma}^{2}(k)$,  $\widehat{\mu}_{0}(k) = \overline{\mu}(k)$,  $S_{0}(k) = 0$ and $n_{0}(k) = 0$  for all $k \in  \mathcal{W}$
 ***for***  $t = 1, \dots, T$
	 1. sample $\mu_{t}^{\prime}(k) \sim \mathcal{N}(\widehat{\mu}_{t-1}(k),\widehat{\sigma}_{t-1}^{2}(k)) \text{ for all } k \in \mathcal{W}$
	 2. pick $W_t = \arg\max_{k\in \mathcal{W}} \mu_{t}^{\prime}(k)$ , let $W_t = k^{\prime}$
	 3. observe $Y_t$
	 4. update 
$$
  \begin{align}
  	S_t(k^{\prime}) = S_{t-1}(k^{\prime})+ Y_t \\
 		n_t(k^{\prime}) = n_{t-1}(k^{\prime})+ 1
  \end{align} 
$$
	 5. update (using the formulas above) 
 $$ 
   \begin{align}
    \widehat{\sigma}_{t}^2(k) &= \cfrac{1}{\cfrac{n_t(k)}{\sigma^2(k)}+\cfrac{1}{\overline{\sigma}^2(k)}}  \\ \\
 \widehat{\mu}_{t}(k) &= \left(\frac{S_t(k)}{\sigma^2(k)} + \frac{\overline{\mu}(k)}{\overline{\sigma}^2(k)}\right) \; \widehat{\sigma}^2_{t}(k) 
\end{align} 
$$


In practice, often we assume $\sigma^2(k) = 1$, and $\overline{\mu}(k) = 0$ and $\overline{\sigma}(k) = 1$ for all $k \in \mathcal{W}$, means the potential reward distributions for all arms have variance $1$ and the prior distribution of the means are standard normal distributions. In this case, the parameters of the posterior distribution is simplified to,

$$
\begin{align}
    \widehat{\sigma}^2_{t}(k) = \frac{1}{n_{t}(k) + 1} \\
    \widehat{\mu}_{t}(k) = S_{t}(k) \times \widehat{\sigma}^2_{t}(k)
\end{align}
$$

## Alternative Formulations

Although Thompson Sampling is a randomized algorithm in nature,  but the arm selection in line 3 in the general case is a deterministic procedure (we just take the maximum in the realized sample). It is also possible to introduce another level of randomization (and therefore more exploration)  by first calculating arm selection probability vector $e_t = (e_t(1), e_t(2), \ldots, e_t(k))$, where 
$$
e_t(k) = \mathbb{P}(\mu_t(k) = \max_{l \in \mathcal{W}} \mu_t(l))
$$
which is the probability that arm $k$ has the best mean, and then we can select the arm at time $t$ randomly by, 
$$
\begin{align}
    {W_t \sim \text{Multinomial}(1, e_t)}    
\end{align}
$$

So first we need to calculate these probabilities then $W_t$ is picked from a Multinomial distribution. So any arm $k$ with nonzero $e_t(k)$ has a chance to be picked, so algorithm is less exploiting the current arm with best sampled $\mu_t(k)$compared to the deterministic case. In this case, we expect that eventually the optimal arm will have the highest probability to be picked after enough exploration.  In practice, it is not always easy to compute these probabilities analytically, but assuming the potential reward distributions are independent we can perform Monte Carlo simulation to approximate these probabilities. 



## Some Intuitions

 Thompson sampling the exploration is driven by randomness of the distribution of the mean parameter. If the posterior distribution is wide spread,  wide variation of sampled mean is obtained, resulting in greater exploration. With more data, the posterior distribution is expected to converge towards the truth, and exploration with decrease. This way, the algorithm handles the exploration-exploitation trade-off.

## Regret Analysis of Thompson Sampling

We will give some details of the Bayesian Regret analysis of Thompson sampling algorithm, and the proof is motivated from the proof given in Lattimore and Szepesvari (2020). However there is anlso a frequentist analysis of Thompson sampling, and we refer the reader to the work of Agrawal and Goyal (2012) for the frequentist analysis. First we introduce some notations, let $Y_t(k) \in [0, 1]$$, $\forall t, \text{ and } \forall k$, i.e., all potential rewards for all arms in all time points are bounded random variables. Recall bounded random variables are also a special case of sub-Gaussian random variables, in particular we have $\left(Y_t(k) - \mu(k) \right) \sim s\mathcal{G}\left(\frac{1}{2}\right)$, where $\mu(k) = \mathbb{E}[Y_t(k)]$.  Like UCB we will assume we are only dealing with the **clean event**, where the clean event is defined as following, 

$$
\mathfrak{C} = \left\{ \forall t \in [T], \forall k \in [K], \left|\widehat{\mu}_{t-1}(k) - \mu(k) \right| < \sqrt{\frac{2 \log(1/\delta)}{1 \vee  n_{t-1}(k)}} \right\}
$$

Under the assumption that the rewards are bounded in $[0,1]$, we can show that  $\mathbb{P}\left(\mathfrak{C}^c\right) \leq 2 T K \delta$, i.e., the event happens $\mathfrak{C}$ happens with high probability (we already discussed this issue before). Recall this argument allows us to apply Hoeffding's bound for all arms in all time points.

Now before going to the Bayesian regret analysis, we need to define Bayesian bandit and Bayesian regret. The Bayesian Bandit setting is same as before, but there is one crucial difference that is - *at the beginning of the game, the set of reward distributions (which we call environment) is drawn from some known set of distributions known as priors and then the game is being played*.   To formalize this we denote the set of prior distributions with $\mathbb{P}^{\theta} = \{\mathbb{P}^{\theta(k)}: k \in [K] \}$, now let $\nu \sim \mathbb{P}^{\theta}$, be a random environment drawn from the priors and then we let the reward distributions associated with this prior with $\mathbb{P}^{\mu^{\nu}} = \left(\mathbb{P}^{\mu^{\nu}(k)}: k \in[K]\right)$. Here for arm $k$ is  $Y_t(k) \sim \mathbb{P}^{\mu^{\nu}(k)}$ , with $\mu^{\nu}(k) = \mathbb{E}[Y_t(k)]$ is the mean of the reward distribution of arm $k$ for the sampled environment $\nu$. 
For the environment $\nu$, we can define the frequentist regret as following 
$$
\mathbb{E} \left[ \mathcal{R}_{T} \mid \nu \right] = \mathbb{E} \left[ \sum_{t=1}^T\left(\mu^{\nu*}-\mu^{\nu}(W_t)\right) \right]
$$
Note this is conditional on the environment and here $\mu^{\nu*} = \max_{k \in [K]} \mu^{\nu}(k)$, and similarly we can also define $k^{\nu*} =  \arg\max_{k \in [K]} \mu^{\nu}(k)$. The Bayesian regret is the expectation of this random quantity,  over the randomness of the environment, i.e., 
$$
\mathbb{E}(\mathcal{R}^{\mathcal{B}}_T):=\underset{\nu \sim \mathbb{P}^{\theta}}{\mathbb{E}}[\mathbb{E}[\mathcal{R}_{T} \mid \nu]] 
$$
So in summary the idea of the Bayesian regret is same as the frequentist regret, first we calculate regret conditional on the environment $\nu$ and then we take another level of  expectation and get the Bayesian regret. We will generally write the Bayesian regret as,
$$
\mathbb{E} \left[ \mathcal{R}^{\mathcal{B}}_{T} \right] = \mathbb{E} \left[ \sum_{t=1}^T\left(\mu^{\nu*}-\mu^{\nu}(W_t)\right) \right]
$$

where in this case the expectation is taken with respect to the randomness of both the environment $\nu$ and arm selection $W_t$ from Thompson sampling. Now we are ready to do the Bayesian regret analysis of Thompson Sampling.

**Theorem** (Bayesian Regret of Thompson Sampling). 
Let $\mathbb{P}^{\theta} = \{\mathbb{P}^{\theta(k)}: k \in [K] \}$ be the set of prior distributions, and $\forall \nu \sim \mathbb{P}^{\theta}$  let  $\mathbb{P}^{\mu^{\nu}} = \left(\mathbb{P}^{\mu^{\nu}(k)}: k \in[K]\right)$ be the set of reward distributions. Assume the rewards are bounded random variables in $[0, 1]$, i.e., $Y_{t}(k) \sim s\mathcal{G}(\frac{1}{2})$ for all $k \in \mathcal{W}$. Then under the clean event, we can show that the Bayesian regret of Thompson Sampling is bounded as,
$$
\mathbb{E}(\mathcal{R}^{\mathcal{B}}_T) \leq O\left(\sqrt{KT \log(T)}\right)
$$

***Proof***
Let $\nu \sim \mathbb{P}^{\theta}$, and let, 
$$
k^{\nu*}=\operatorname{argmax}_{k \in[K]} \mu^{\nu}(k)
$$
be the optimal arm in the environment $\nu$. Now since $\nu$ is random so in this case $k^{\nu*}$ is also random. From now on we will use a simpler notation and omit writing $\nu$, so we will simply write $k^*$ instead of $k^{\nu*}$ and write $\mu(k)$ instead of $\mu^{\nu}(k)$. Let's start with the Bayesian regret definition. 
$$
\begin{align}
\mathbb{E}(\mathcal{R}^{\mathcal{B}}_T) &= \mathbb{E}\left[\sum_{t=1}^T\left(\mu(k^{*})-\mu(W_t)\right)\right] \\
&= \sum_{t=1}^T\mathbb{E}\left[\mu(k^{*})-\mu(W_t)\right]\\
&=\sum_{t=1}^T \mathbb{E}\;\left[\mathbb{E} \left(\mu(k^{*})-\mu(W_t) \mid \mathcal{F}_{t-1}\right)\right]
\end{align}
$$
where $\mathcal{F}_t=\sigma\left(W_1, Y_1, \ldots, W_t, Y_t\right)$ is the $\sigma$-algebra generated by the interaction sequence by the end of round $t$. Further let, 
$$
U_t(k)=\left(\widehat{\mu}_{t-1}(k)+\sqrt{\frac{2 \log (1 / \delta)}{1 \vee n_{t-1}(k)}}\right)
$$
be the upper confidence bound. The quantity $U_t(k)$ is $\mathcal{F}_{t-1}$-measurable. This would be useful in the following part of the proof. We start with the conditional part from the regret,
$$
\begin{align}
\mathbb{E}\left[\mu(k^{*})-\mu(W_t) \mid \mathcal{F}_{t-1}\right]  &=\mathbb{E}\left[\mu(k^{*})-U_t(W_t)+U_t(W_t)-\mu(W_t) \mid \mathcal{F}_{t-1}\right] \\
& =\mathbb{E}\left[\mu(k^{*})-U_t\left(k^{*}\right)+U_t(W_t)-\mu(W_t) \mid \mathcal{F}_{t-1}\right] \\
& =\mathbb{E}\left[\mu(k^{*})-U_t\left(k^{*}\right) \mid \mathcal{F}_{t-1}\right]+\mathbb{E}\left[U_t(W_t)-\mu(W_t) \mid \mathcal{F}_{t-1}\right]
\end{align}
$$
where in the second line we used $\mathbb{E}(U_t(W_t) \mid \mathcal{F}_{t-1}) = \mathbb{E}(U_t(k^{*}) \mid \mathcal{F}_{t-1})$, i.e., the upper bound in expectation conditional on the history picked by the Thompson Sampling and upper bound for the optimal arm conditional on the same history is same. This is a very important property and one of the key steps in the proof. Here this holds since, for any arm $k \in \mathcal{W}$ we have
$$
\mathbb{P}\left(k^{*} = k \mid \mathcal{F}_{t-1}\right)=\mathbb{P}\left(W_t = k \mid \mathcal{F}_{t-1}\right) \quad \text { a.s. }
$$
this holds by definition of the Thompson sampling. Note that this essentially means conditional distribution of $k^{*}$ and conditional distribution of $W_t$ given the history $\mathcal{F}_{t-1}$ are identical. Finally taking conditional expectation gives following relation,
$$
\begin{align}
\mathbb{E}\left[\mu(k^{*})-\mu(W_t) \right]  =\mathbb{E}\left[\mu(k^{*})-U_t\left(k^{*}\right) \right]+\mathbb{E}\left[U_t(W_t)-\mu(W_t) \right]
\end{align}
$$

This allows us to write,
$$
\begin{align}
\mathbb{E}(\mathcal{R}^{\mathcal{B}}_T) 
&= \sum_{t=1}^T\mathbb{E}\left[\mu(k^{*})-\mu(W_t)\right]\\
&= \sum_{t=1}^T \left(\mathbb{E}\left[\mu(k^{*})-U_t\left(k^{*}\right) \right]+\mathbb{E}\left[U_t(W_t)-\mu(W_t) \right]\right)  \\
&\leq \sum_{t=1}^T \mathbb{E}\left[U_t(W_t)-\mu(W_t) \right]
\end{align}
$$

where in the last line since with Hoeffding's bound the first term is negative so we can drop this.  
Now we can start with 
$$
\begin{align}
\sum_{t=1}^T U_t(W_t)-\mu(W_t) &=  \sum_{t=1}^T \sum_{k=1}^K \mathbf{1}\left\{W_t=k\right\}\left(U_t(k)-\mu(k)\right) \\ \\
&=   \sum_{k=1}^K \sum_{t=1}^T \mathbf{1}\left\{W_t=k\right\}\left(U_t(k)-\mu(k)\right)  \\
&=  \sum_{k=1}^K \sum_{t=1}^T \mathbf{1}\left\{W_t=k\right\} \left( \hat{\mu}_{t-1}(k)  + \sqrt{\frac{2 \log (1 / \delta)}{1 \vee n_{t-1}(k)}} - \mu(k) \right) \\ 
&\leq  \sum_{k=1}^K \sum_{t=1}^T \mathbf{1}\left\{W_t=k\right\} \left(\mu(k) + \sqrt{\frac{2 \log (1 / \delta)}{1 \vee n_{t-1}(k)}} + \sqrt{\frac{2 \log (1 / \delta)}{1 \vee n_{t-1}(k)}} -  \mu(k)\right) \\ 
&= \sum_{k=1}^K \sum_{t=1}^T \mathbf{1}\left\{W_t=k\right\} \sqrt{\frac{8 \log (1 / \delta)}{1 \vee n_{t-1}(k)}}  \\
&= \sqrt{  8 \log (1 / \delta)} \; \sum_{k=1}^{K} \sum_{t = 1}^{T} \frac{1}{\sqrt{n_{t-1}(k)}} \mathbf{1}\{W_t = k\}\\
&\leq \sqrt{  8 \log (1 / \delta)} \; \sum_{k=1}^{K} \underbrace{\int_{1}^{n_{T}(k)} \frac{1}{\sqrt{ s }} ds}_{\approx  2 \sqrt{n_{T}(k)}}\\
&\leq \sqrt{  8 \log (1 / \delta)} \; \sum_{k=1}^{K} \sqrt{n_{T}(k) }\\
&\leq \sqrt{8 \log \left(\frac{1}{\delta}\right)} \sqrt{ KT }\\
&= \sqrt{ 16 K T \log(T)}\\ 
\end{align}
$$
where we used Jensen's inequality since $\sqrt{x}$ is a concave function, so we have, 
 $$
\frac{1}{K} \sum_{a=1}^{K} \sqrt{n_{T}(k)} \leq \sqrt{\frac{1}{K} \sum_{a=1}^{K} n_{T}(k)} = \sqrt{ \frac{T}{K} }
$$
so we have,
 $$
\sum_{a=1}^{K} \sqrt{n_{T}(k)} \leq K \sqrt{ \frac{T}{K} } = \sqrt{ KT }
$$
and at the last line we plugged $\delta = 1/T^2$. Finally putting everything together we get,

$$
\begin{align}
\mathbb{E}(\mathcal{R}^{\mathcal{B}}_T) 
&\leq \mathbb{E}\left[ \sum_{t=1}^T U_t(W_t)-\mu(W_t) \right]  \\
&= \sqrt{ 16 K T \log(T)} \leq  O\left(\sqrt{KT \log(T)}\right)
\end{align}
$$

So the Bayesian Regret of Thompson Sampling is $O\left(\sqrt{KT \log(T)}\right)$ under the clean event. $\blacksquare$
